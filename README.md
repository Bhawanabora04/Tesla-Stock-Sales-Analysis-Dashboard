# 🚗 Tesla Stock Sales Analysis Dashboard

## 📌 Project Overview

The **Tesla Stock Sales Analysis Dashboard** is an interactive Power BI dashboard created to analyze Tesla vehicle models, pricing, EMI, sales distribution, and driver-assistance system (DAS) insights.

The dashboard transforms car sales data into interactive visualizations that make it easier to understand pricing patterns, customer financing indicators, geographic sales distribution, and DAS preferences.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze Tesla car pricing patterns.
- Understand average and median vehicle prices.
- Analyze average EMI values.
- Study the distribution of Tesla sales across different states.
- Analyze Driver Assistance System (DAS) preferences.
- Compare sales across different Tesla models.
- Create an interactive dashboard for car sales analysis.

## 📊 Dashboard Features

### 1. Pricing Analysis

The dashboard provides key pricing metrics including:

- Average Price
- Median Odometer
- Average EMI

These metrics provide a quick overview of vehicle pricing and financing-related information.

### 2. State-wise Sales Analysis

The dashboard visualizes Tesla sales across different U.S. states.

This helps identify states with higher and lower sales volumes and provides a geographic perspective of the dataset.

### 3. Tesla Model Analysis

The dashboard includes Tesla model-level information to explore differences in vehicle sales and pricing across models.

### 4. Driver Assistance System Analysis

A donut chart shows the distribution of vehicle prices based on Driver Assistance System (DAS) categories, including:

- Autopilot
- Full Self-Driving
- Enhanced Autopilot

This helps understand the relationship between vehicle pricing and available driver-assistance features.

### 5. Interactive Car Visualization

The dashboard includes a visual representation of a Tesla vehicle along with an interactive **3D View** element to improve dashboard presentation and user experience.
